## 1. ANOMALY & CONTEXT
When establishing a greenfield product or game project using a retro reference work (e.g., CPS-1 arcade architecture), agent misinterpretation of 'Principle of Least Action' and 'Zero-Dep' caused regression into primitive Canvas geometric polygons and 1990s hardware constraints rather than a high-definition remake (Primitive Attractor Trap).

## 2. RATIFIED RULE (THE RULING)
1. INV_AST_001 (Fidelity Tier & Zero-Primitive Invariant, DoF = 0):
   When a project is designated as 'Remake' or 'Contemporary Production', generating crude geometric placeholder polygons is prohibited. Asset formulation and storyboarding stages MUST employ multimodal generation tools directly configured for production-grade concept resolution (HD/4K).

2. INV_AST_002 (Remake vs. Retro-Demake Decoupling, DoF = 0):
   When a retro reference work is selected, hardware limitations (such as CPS-1 or NES resolution and palette constraints) SHALL NOT be emulated. Only core mathematical gameplay loops and mechanics are abstracted from the reference work; audiovisual presentation MUST be constructed using current industry standards.

## 3. VERIFICATION ASSERTION
- Inception case ledgers (CAS_*) verify visual storyboards are generated via multimodal tool interfaces or explicit target resolution parameters.
- Placeholder primitive drawings are rejected at the verification turnstile with 'REJECT_PRIMITIVE_ASSET'.
